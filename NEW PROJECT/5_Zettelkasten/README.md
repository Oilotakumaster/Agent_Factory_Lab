# 🧠 5_Zettelkasten (卡片盒筆記)

這裡是你的第二大腦知識庫，與一般資料夾架構不同，這裡注重檔案與檔案之間的「雙向連結 (**[[]]**）」。

建議將知識提煉後，以卡片的形式存放在這裡。也可以建立子分類：
- **5a_Fleeting (閃念筆記)**：隨手的想法，尚未整理（也可以統一集中在 `0_Inbox`）。
- **5b_Literature (文獻筆記)**：你讀過的書、文章、影片的摘要，要**用你自己的話**寫下來。
- **5c_Permanent (永久筆記)**：經過思考、濃縮後的核心概念。每個概念寫成獨立的一張卡片，並且在筆記中建立連結，讓知識網互相串連。
